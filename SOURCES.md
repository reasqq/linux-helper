# Источники и происхождение учебных материалов

## Книга

Дэниел Г. Грэм. *Этичный хакинг. Практическое руководство по взлому*. Русское издание: СПб., Питер, 2022. ISBN 978-5-4461-1952-3. Английское издание: *Ethical Hacking: A Hands-on Introduction to Breaking In*, No Starch Press, 2021.

Содержание книги использовано как карта тем. Объяснения, вопросы, схемы и примеры в Linux Helper написаны заново. PDF, страницы книги, исходные рисунки и листинги не распространяются в репозитории и пакетах приложения.

| Темы книги | Путь в Linux Helper |
| --- | --- |
| Глава 1: виртуальная лаборатория | Основа пентеста, правовые границы |
| Главы 2–4: ARP, пакеты, TCP и сокеты | Трафик и протоколы |
| Главы 5–6: шифрование, ключи, TLS | Криптография и TLS |
| Главы 7–8: социальная инженерия, OSINT, инвентаризация | Разведка и оценка |
| Главы 9–11: фаззинг, символьное выполнение, граница ядра | Анализ уязвимостей |
| Главы 12–13: пароли, SQL-инъекции, XSS | Веб-безопасность |
| Главы 14–15: сегментация, идентичность, AD/LDAP/Kerberos | Корпоративная сеть |
| Глава 16: укрепление и дальнейшая практика | Укрепление и анализ |

Техники в книге относятся к изданию 2021–2022 годов; Linux Helper объясняет концепции и защитные выводы. Для текущих требований и версий инструментов следует сверяться с актуальной документацией.
